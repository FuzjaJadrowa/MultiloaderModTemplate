# MultiloaderModTemplate

My template for creating multiloader mods for Minecraft!

This template features separate branches for different configurations:
- [`multiversion`](../../tree/multiversion) - Template supporting multiple target Minecraft versions (using Stonecutter).
- [`singleversion`](../../tree/singleversion) - Template targeting a single Minecraft version.

## How to use
Clone this repository and checkout the branch for the setup you want to use:
```bash
git clone -b <branch> https://github.com/FuzjaJadrowa/MultiloaderModTemplate.git
```
